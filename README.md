# 🔬 Virtual Physics Laboratory – Screw Gauge Measurement Simulation

> An interactive web-based Virtual Physics Laboratory that simulates the working of a **Screw Gauge (Micrometer Screw Gauge)**. This project enables students to perform measurements virtually, understand the working principle of the instrument, record observations, and practice experiments without requiring physical laboratory equipment.

---

## 📖 About the Project

The **Screw Gauge Measurement Simulation** is designed to provide students with a realistic virtual laboratory experience. It replicates the operation of a real screw gauge, allowing users to measure the diameter or thickness of various objects while understanding concepts such as:

- Main Scale Reading (MSR)
- Circular Scale Reading (CSR)
- Least Count
- Pitch
- Zero Error
- Corrected Reading
- Final Measurement

The project aims to bridge the gap between theoretical knowledge and practical laboratory experience through an intuitive and interactive interface.

# 🚀 How to Run

### Method 1 (Recommended)

1. Download or Clone the repository.
2. Open the project in Visual Studio Code.
3. Install the **Live Server** extension.
4. Right-click on **index.html**.
5. Click **Open with Live Server**.

The project will launch automatically in your default browser.
